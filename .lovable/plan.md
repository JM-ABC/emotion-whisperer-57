
# 섬 배치 중앙 정렬 + 텍스트 z-index + 크기 확대

## 문제점 (스크린샷 기반)
1. 섬들이 "Core Memory" 헤더 기준으로 오른쪽에 치우쳐 있음 - x좌표 평균이 50%보다 높음
2. 섬 이름 텍스트가 아래 섬 이미지에 가려져 보이지 않음 - z-index 문제
3. 이미지에 검은 네모 배경이 보임 - 아직 누끼가 아님
4. 섬 크기가 작음 (기본 80px)

## 변경 사항

### 1. IslandNode.tsx - 배치 좌표 왼쪽으로 보정

스크린샷을 보면 전체가 오른쪽으로 밀려있으므로 x좌표를 왼쪽으로 약간 보정합니다:

```text
현재:                        수정 후:
50%, 6%                      50%, 5%
35%, 22%  /  65%, 22%        32%, 22%  /  62%, 22%
25%, 40%  /  50%, 38%  /  75%, 40%    22%, 42%  /  47%, 40%  /  72%, 42%
38%, 58%  /  62%, 58%        35%, 60%  /  60%, 60%
```

x좌표 평균을 기존 ~50%에서 ~47%로 약간 왼쪽으로 이동하여 시각적 균형을 맞춤

### 2. IslandNode.tsx - 텍스트를 이미지 앞으로 (z-index)

- 라벨 `motion.div`에 `z-50` 클래스 추가하여 다른 섬 이미지 위에 표시되도록 함
- 텍스트 배경에 반투명 배경(backdrop) 추가로 가독성 확보:
  - `bg-background/60 backdrop-blur-sm px-2 py-0.5 rounded` 스타일 적용

### 3. IslandNode.tsx - 섬 크기 확대

- 기본 사이즈를 `80px`에서 `100px`으로 확대
- 최대 사이즈를 `130px`에서 `160px`으로 확대
- `Math.max(100, Math.min(160, 100 + count * 12))`

### 4. IslandNode.tsx - 누끼 효과 강화

- 이미지에 `mix-blend-mode: screen` 다시 적용하여 검은 배경을 투명하게 처리
  - 이전에 제거했으나, AI 생성 이미지가 검은 배경을 가지고 있으므로 screen 블렌드가 필요
