
# 스크롤 없이 모든 섬 한눈에 보이기

## 문제
- 헤더의 상단 패딩(pt-12)이 너무 큼
- 기쁨의 섬(mt-8), 슬픔의 섬(mt-8) 등 행 간 마진이 넓음
- IslandNode의 최소 크기(90px)가 커서 전체 높이가 뷰포트를 초과

## 변경 사항 (2개 파일)

### 1. Index.tsx - 여백 줄이기
- 헤더: `pt-12 pb-6` → `pt-6 pb-2` (상단 여백 절반으로)
- 그리드 영역: `py-4` → `py-1`
- Row 1 기쁨의 섬: `mt-8` → `mt-2`
- Row 3 슬픔의 섬: `mt-8` → `mt-3`
- 기억 구슬 섹션: `mt-2` → `mt-1`
- 오늘의 상태 섹션: `mt-4` → `mt-2`

### 2. IslandNode.tsx - 섬 크기 축소
- 섬 최소 크기: `90px` → `70px`, 최대 크기: `140px` → `110px`
- 성장 계수: `count * 12` → `count * 8`
- 이렇게 하면 각 섬이 약 20px씩 작아져 전체 높이가 크게 줄어듦

## 결과
- 헤더 + 8개 섬 + 하단 요소가 모두 한 화면에 들어옴
- 섬 간 비율과 배치 균형은 유지
