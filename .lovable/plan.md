
# 모바일에서 스크롤 없이 모든 요소 표시하기

## 현재 문제
모바일(375x812) 기준으로 하단 "오늘의 기억 기록하기" 버튼과 카운트 텍스트가 하단 네비게이션 바 아래로 밀려남

## 변경 사항

### 1. IslandNode.tsx - 섬 크기 추가 축소
- 최소 크기: `70px` → `60px`, 최대 크기: `110px` → `90px`
- 성장 계수: `count * 8` → `count * 6`
- 라벨 간격: `mt-2` → `mt-1` (이미지와 라벨 사이)

### 2. Index.tsx - 여백 추가 압축
- 헤더: `pt-6 pb-2` → `pt-4 pb-1`
- 그리드 컨테이너: `px-6 py-1` → `px-4 py-0`
- Row 1 기쁨의 섬: `mt-2` → `mt-1`
- Row 3 슬픔의 섬: `mt-3` → `mt-2`
- 오늘의 기록 버튼: 패딩 `p-4` → `p-3`
- 메모리 카운트: `mt-4 pb-4` → `mt-2 pb-2`

## 수정 파일

| 파일 | 변경 |
|------|------|
| `src/components/IslandNode.tsx` | 섬 크기 60-90px, 라벨 mt-1 |
| `src/pages/Index.tsx` | 헤더/그리드/버튼 여백 축소 |
