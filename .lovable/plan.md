

# 섬 배치 밸런스 조정

## 현재 상태

현재 그리드 레이아웃의 섬 배치 순서:
- **Row 1**: 기쁨의 섬 (중앙) — 아래 섬들과 간격이 넓음
- **Row 2**: 평온의 섬 (좌), 사랑의 섬 (우)
- **Row 3**: 희망의 섬, 슬픔의 섬, 분노의 섬
- **Row 4**: 불안의 섬 (좌), 피로의 섬 (우)

## 변경 사항 (Index.tsx)

### 1. 기쁨의 섬을 아래로 내리기
- Row 1의 기쁨의 섬 wrapper에 `mt-4`를 추가하여 헤더와의 간격은 유지하면서 아래 행과 더 가깝게 배치

### 2. 슬픔의 섬을 아래로 내리기
- Row 3의 3개 섬 중 슬픔의 섬(ISLANDS[4])만 개별 wrapper로 분리하여 `mt-3`을 적용
- 나머지 희망/분노의 섬은 현재 위치 유지

### 3. 전체 간격 조정
- 그리드의 `gap-y-2`를 `gap-y-0`으로 줄이고, 각 행에 개별 마진을 줘서 행 간 간격을 세밀하게 제어
- Row 2에 `mt-1`, Row 3에 `mt-2`, Row 4에 `mt-1` 적용으로 전체적으로 더 균일한 분포 구현
